# Help Desk Lab

Este repositório é meu laboratório de estudos de suporte de TI. A ideia é registrar problemas comuns de atendimento e o caminho que eu usaria para diagnosticar cada situação, em vez de guardar apenas uma lista de comandos.

Estou usando os casos para praticar principalmente Windows, rede, impressoras e atendimento ao usuário.

## Casos registrados

| # | Situação | O que estou praticando |
|---|---|---|
| 01 | Computador conectado, mas sem acesso à internet | IP, gateway, DNS e testes de conectividade |
| 02 | Impressora aparece offline | fila de impressão, serviço Spooler e conectividade |
| 03 | Computador muito lento | inicialização, processos, armazenamento e diagnóstico básico |
| 04 | Usuário não consegue acessar uma pasta de rede | conectividade, caminho de rede e permissões |

Vou adicionar os casos conforme avanço nos estudos. Cada arquivo contém o cenário, perguntas que eu faria ao usuário, testes, comandos e uma forma de registrar o encerramento do chamado.

## Ferramentas que aparecem no laboratório

- Prompt de Comando e PowerShell
- `ipconfig`, `ping`, `nslookup` e `tracert`
- Gerenciador de Tarefas
- Serviços do Windows
- Fila de impressão
- Conceitos básicos de TCP/IP e DNS

## Observação

Os chamados deste repositório são cenários de laboratório para estudo. Não representam atendimentos realizados em uma empresa.
